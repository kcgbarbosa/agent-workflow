Call the Skill tool twice, for "grilling" and "domain-modeling".

Read the ADRs and the code before the first round, and let them shape the options. A question holds only its options and your recommendation, with no ADR or code preface. Note each conflict you find. When the frontier is empty, check every settled answer against the ADRs and the code in one pass, and ask about the conflicts as the last round.
