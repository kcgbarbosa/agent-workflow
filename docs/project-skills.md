# Project skills

These skills live in project repos, not in this repo. This file lists that they exist and which kind of project each belongs to. Each skill's own description says how it works.

Update this file when a project skill is added, renamed or removed. The `retro` skill checks it.

| Skill              | What it does                                                                                                       | Who runs it                                      | Kind of project |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ | --------------- |
| `demo`             | Starts the local stack of a branch so KC can click through it as a user role                                       | KC asks the agent                                | Web app         |
| `ui-review`        | Screenshots a UI change at phone width in two browsers, in English and Spanish, as each user role the diff affects | The loop or an agent, when a diff touches the UI | Web app         |
| `scan-specs`       | Scans the specification documents of a document corpus                                                             | KC, never an agent                               | Document corpus |
| `scan-images`      | Scans the images of a document corpus                                                                              | KC, never an agent                               | Document corpus |
| `extract-receipts` | Extracts receipts                                                                                                  | Run on the ThinkPad                              | Bookkeeping     |
| `recibo-edge-case` | Handles the edge cases of receipt extraction                                                                       | Run on the ThinkPad                              | Bookkeeping     |
